# What is Zeen
**Zeen** is a modern systems programming language designed for simplicity of program flow control.
It provides toolchains and compiler's rules to easily operate the data and automatically drop it after usage with move semantics to avoid any runtime overhead.
The main idea is to create a tool to develop efficient software where most errors are catched at compile time.

Zeen took out many design choices from Rust and Zig programming languages, which makes it more familiar for most developers.
Besides that it introduces its own approach to ownership, memory management, and compile-time features.

# Why was Zeen created
Personally me (founder of language and writer of first version of this documentation - [@mealet](https://github.com/mealet)) was very fancy
about Rust's ownership and auto-drops system, but also I wanted more freedom like in Zig. I've chosen freedom of Zig and, once a day, I've got untrackable
segmentation fault which I couldn't fix. It is probably my skill issue, but then I've decided to create "free" systems language with automatic data drops and ownerships system.
