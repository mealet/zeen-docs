## Quick Installation

<Tabs>
   <TabItem label="Linux / MacOS / FreeBSD" icon="linux">
      <Steps>

      1. Install Zeen's latest version:
         ```bash
         curl -fsSL https://github.com/mealet/zeen/releases/latest/download/install.sh | sh
         ```

      2. Check the version with:
         ```bash
         zeen --version
         ```

      </Steps>
   </TabItem>

   <TabItem label="Windows" icon="seti:windows">
      <Steps>

      1. Install Zeen's latest version (with powershell):
         ```bash
         [Net.ServicePointManager]::SecurityProtocol=[Net.ServicePointManager]::SecurityProtocol -bor [Net.SecurityProtocolType]::Tls12;iex ((New-Object Net.WebClient).DownloadString('https://github.com/mealet/zeen/releases/latest/download/install.ps1'))
         ```

      2. Check the version with:
         ```bash
         zeen --version
         ```

      </Steps>
   </TabItem
</Tabs>

## Build From Source

<Steps>

1. Install the [Rust Programming Language](https://rust-lang.org/) from the official website.

2. Install [LLVM 22](https://www.llvm.org/docs/GettingStarted.html) following the tutorial.

3. Clone the actual **Zeen** repository:

   ```bash
   git clone https://github.com/mealet/zeen
   ```

4. Open the cloned directory in the terminal and build the compiler:

   ```
   cd compiler
   cargo build --release
   ```

5. You'll find the executable in the `target/release` directory:

   <FileTree>
      - compiler
         - target
            - release
              - **zeen** compiler executable (on Windows `zeen.exe`)
              - ...
   </FileTree>

</Steps>

## Compiler Usage

<Steps>

1. Create new `.zn` file and write code:
   
   <Code code={`fn main() {
       @println("Hello, World!");
}`} lang="zn" title="main.zn" />

2. Compile source to binary:

   ```bash
   zeen main.zn output
   ```

   To see all supported targets:

   ```bash
   zeen --targets-list
   ```

3. Run the compiled program:

   ```bash
   ./output
   ```
   ```
   Hello, World!
   ```

</Steps>
