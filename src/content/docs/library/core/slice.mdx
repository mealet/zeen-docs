## Structures
<Card title="Range">
  Ranges variations:
  * `lo..hi` - `{ start: Some, end: Some }`
  * `lo..=hi` - `{ start: Some, end: Some + 1 }`
  * `lo..` - `{ start: Some, end: None }`
  * `..hi` - `{ start: None, end: Some }`
  * `..=hi` - `{ start: None, end: Some + 1 }`
  * `..` - `{ start: None, end: None }`

  ----

  **Fields:**
  ```zeen
  pub start: Option[usize],
  pub end: Option[usize],
  ```
  **Methods:**
  ```zeen

  pub fn last(*const self) Option[usize];
  ```

  **Interfaces:**

  - `core.iter` : `Iterator`
</Card>
